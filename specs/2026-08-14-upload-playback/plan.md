- [ ] `backend/src/storage/`: `storage.module.ts` + `storage.service.ts` — wraps the Supabase Storage REST API with Node's built-in `fetch` + service-role key (no new SDK): `uploadObject(bucket, key, nodeReadableStream, contentType)` (POST `/storage/v1/object/<bucket>/<key>`, body = raw stream, `x-upsert: true`), `createSignedUrl(bucket, key, expiresInSeconds = 3600)` (POST `/storage/v1/object/sign/<bucket>/<key>`) and `publicUrl(bucket, key)`, `deleteObject(bucket, key)` (DELETE `/storage/v1/object/<bucket>/<key>`); non-2xx → `InternalServerErrorException`
- [ ] `backend/src/tracks/`: `tracks.module.ts` + `tracks.controller.ts` + `tracks.service.ts`: `POST /tracks` (JwtAuthGuard) — multer `FileFieldsInterceptor([{name:'file',maxCount:1},{name:'cover',maxCount:1}])` with `diskStorage` in the OS temp dir (stream to storage, never hold in server memory — tech-stack), `limits.fileSize = 100MB`, `fileFilter` allowlist: audio MIME `audio/mpeg, audio/mp4, audio/x-m4a, audio/wav, audio/ogg, audio/flac, audio/aac, audio/webm` (reject otherwise → 400), fields `title` + `artist` required (400 if missing/empty), `album` optional, `cover` optional (image MIME only); flow: parse duration via `music-metadata` `parseFile` (never trust client duration — tech-stack) → create `Track` row (owner = `req.user.id`, `durationMs`, `coverUrl` = public bucket URL when cover given) → stream audio to `audio/<trackId>.<ext>` → set `audioStorageKey` → unlink temp files → 201 `{track}` with freshly-minted signed `audioUrl`; `GET /tracks` → 200 array of the caller's tracks (owner-scoped), each with a fresh signed `audioUrl` (1h expiry)
- [ ] `backend/src/tracks/tracks.service.spec.ts`: exactly 4 unit tests, test doubles only in test files (storage service mocked; duration parsing runs on a real synthesized WAV buffer written in the test): (1) create → row with real `durationMs` + storage key set, (2) storage upload failure → throws 500 and temp file cleaned, (3) list → returns owner's tracks with signed URLs, (4) `deleteObject` called in cleanup path
- [ ] `backend/src/tracks/tracks.controller.spec.ts`: exactly 3 unit tests: missing audio file → 400, missing title → 400, non-image cover MIME → 400 (multer filter + controller checks, mocked service)
- [ ] `backend/test/tracks.e2e-spec.ts`: exactly 4 tests against the running app with real local Supabase (pattern from `auth.e2e-spec.ts`, real signup for a real JWT, cleanup deletes the user — cascade removes tracks — and the storage objects via `DELETE /storage/v1/object`): (1) `POST /tracks` without token → 401, (2) upload of a synthesized real WAV (1s of silence, 16 kHz mono 16-bit PCM, written by the test) with `title`+`artist` → 201 with `durationMs` between 900 and 1100, (3) upload without `title` → 400, (4) `GET /tracks` → array of exactly 1, `audioUrl` contains `/object/sign/`
